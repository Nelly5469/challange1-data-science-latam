# Practicando Python para Data Science: Challenge Alura Store

Este es el primer challange de Alura perteneciente a OracleOne del path de Data Science. Se trata de un análisis comparativo entre las tiendas del Sr. Juan para decidir, de manera informada, cuál es la tienda que puede vender. Las principales librerías de Python usadas son Pandas y Plotly.

## Descripción del análisis

Se incluye:

* Análisis de facturación
* Ventas por categoría
* Calificación promedio
* Productos más y menos vendidos
* Envío promedio por tienda

## Herramientas usadas

* Jupyter Notebook: Entorno interactivo para escribir y ejecutar código Python, ideal para análisis de datos y visualización paso a paso.
* pandas: Librería para manipulación y análisis de datos en estructuras tipo DataFrame, facilita la importación, limpieza y análisis de datos tabulares.
* plotly.express: Librería para crear gráficos interactivos y visualizaciones avanzadas, como gráficos de pastel, barras y dispersión.
* matplotlib.pyplot: Librería para crear gráficos estáticos y visualizaciones básicas, útil para mostrar paletas de colores y gráficos simples.

### Ejecución del notebook

Para ejecutar este proyecto desde GitHub:

1. Instala Python
Descarga e instala Python (recomendado versión 3.8 o superior).

2. Instala Jupyter Notebook
Abre la terminal (o CMD en Windows) y ejecuta:

pip install notebook

3. Clona el repositorio
En la terminal, navega a la carpeta donde quieres el proyecto y ejecuta:

git clone https://github.com/Nelly5469/challange1-data-science-latam.git

4. Instala las librerías necesarias
Ejecuta:

pip install pandas plotly matplotlib

5. Abre el Jupyter Notebook
En la terminal, ejecuta:

jupyter notebook

Se abrirá una ventana en tu navegador. Haz clic en AluraStoreLatam.ipynb para abrir el notebook.

Ejecuta las celdas
Ve ejecutando cada celda del notebook para reproducir el análisis y las visualizaciones.
